# 莃棠签到抽卡好感商店插件（astrbot_plugin_xitang）

一个基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的趣味互动插件：每日签到、今日运势、抽卡、好感度、金币商店与赠送礼物。

> 主要面向 QQ（aiocqhttp）适配器；群头衔功能仅支持 QQ 协议端。

## 功能一览

| 功能 | 指令 | 说明 |
| --- | --- | --- |
| 每日签到 | `/签到` | 随机获得 1~100 金币，好感 +1 |
| 今日运势 | `/今日运势` | 品味值 / 运气值 / 厄运值 / 出货率（每天一次） |
| 单抽 | `/抽奖`（`/抽卡`） | 消耗 1 抽奖币，概率出传说/史诗/高级/空白 |
| 五连抽 | `/五连抽`（`/五连`） | 消耗 5 抽奖币 |
| 十连抽 | `/十连抽`（`/十连`） | 消耗 10 抽奖币 |
| 查询记录 | `/查询记录` | 查看累计抽数、各品质次数 |
| 重置记录 | `/重置次数` | 清空抽卡记录（不影响金币/抽奖币） |
| 金币商店 | `/金币商店`（`/商店`） | 查看商品与价格 |
| 购买商品 | `购买 商品名 数量` | 如 `购买糖果 2` |
| 每日金币 | `/获得金币` | 每天领取 200 金币 |
| 每日抽奖币 | `/领取抽奖币`（`/获得抽奖币`） | 每天领取 1~10 抽奖币 |
| 好感查询 | `/好感` | 查看当前好感值 |
| 赠送礼物 | `赠送 礼物名 数量` | 提升好感（糖果/零食/鲜花/小说/蛋糕） |
| 主人打钱 | `打钱 数量` | 仅 master_qq 可用 |
| 群打卡 | `/打卡` | 返回当前群号 |
| 群头衔 | `群头衔 文字` | 设置群头衔（需机器人是群主/管理员） |
| 学说话 | `说 内容` | 好感 ≥100 后可用 |
| 早安/晚安 | `/早上好` `/晚安` `/晚上好` | 问候语 |

> 说明：AstrBot v4 的指令（`/` 开头）需要唤醒前缀或 @ 机器人才会触发；`购买 / 赠送 / 打钱 / 群头衔 / 说` 等自然语言指令无需前缀即可触发。

## 安装

### 方式一：WebUI 安装（推荐）

1. 将本仓库打包为 zip（或直接使用发布的 zip）；
2. 打开 AstrBot WebUI → 插件 → 安装插件 → 上传 zip 安装。

### 方式二：手动放置

```bash
mkdir -p AstrBot/data/plugins
# 将插件文件夹复制到 data/plugins 下，并确保文件夹名与 metadata.yaml 的 name 一致
cp -r astrbot_plugin_xitang AstrBot/data/plugins/
```

然后重启 AstrBot，或在 WebUI 插件页点击重载。

## 配置

插件配置项（WebUI → 插件 → 本插件 → 配置）：

| 配置项 | 类型 | 说明 |
| --- | --- | --- |
| `master_qq` | string | 主人 QQ 号，只有该账号可以使用 `打钱` 指令 |

## 数据存储

用户数据存放在 `data/plugin_data/astrbot_plugin_xitang/user_data.json`，符合 AstrBot 插件规范：

- 不写入插件自身目录，插件更新 / 重装不会丢失用户数据；
- 旧版本（存放在插件目录下的 `user_data.json`）会在首次加载时自动迁移。
